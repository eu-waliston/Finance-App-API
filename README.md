# 💸 Finance App API

Backend de um sistema financeiro pessoal desenvolvido com a stack MERN.

O projeto nasceu inicialmente como uma planilha financeira evoluída e está sendo transformado em uma aplicação web completa com autenticação, dashboard analítico e gerenciamento financeiro moderno.

---

# 🚀 Tecnologias

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

---

# 📦 Funcionalidades atuais (MVP)

## 🔐 Autenticação
- Registro de usuário
- Login com JWT
- Middleware de autenticação

---

## 💸 Transações
- Criar transação
- Listar transações
- Editar transação
- Deletar transação

---

## 🔎 Filtros
- Filtrar por tipo
- Filtrar por categoria
- Filtrar por data

---

## 📄 Paginação
- Paginação de transações
- Controle de páginas
- Total de itens

---

## 🏷️ Categorias
- Criar categoria
- Listar categorias

---

## 📊 Dashboard Analytics
- Summary financeiro
- Resumo mensal
- Balance automático
